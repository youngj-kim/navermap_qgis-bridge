about=View NAVER Map and Street View in an embedded dock or an external browser with bidirectional position and zoom synchronization. Place search and driving routes target South Korea. Create routes with up to five waypoints, inspect turn-by-turn instructions, import saved route history, and export GeoPackage, GeoJSON, Shapefile, or GPX. Includes EN/KR controls and API-provided English instructions for new routes. Internet access and users' own NAVER Maps and NAVER API HUB credentials are required. Embedded mode requires Qt WebEngine and WebChannel; an external-browser fallback is provided. Map tiles are not extracted or registered as QGIS XYZ/TMS layers. Korean and English guides are included.
