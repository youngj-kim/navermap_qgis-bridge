1. 준비와 설치

인증키는 체크리스트·스크린샷·오류 보고에 적지 않습니다. QGIS 3과 4의 외부 브라우저 검사는 순서대로 수행합니다. 기본 포트 8083을 사용하는 이전 QGIS 외부 연동은 종료하고, 기존 브라우저 탭 대신 플러그인에서 새 탭을 엽니다.

2. 우선 확인: 위치와 확대·축소

아래 묶음은 QGIS 3.34 이상 외부 브라우저, QGIS 4 내장 웹 뷰에서 각각 확인합니다. QGIS 4에 내장 웹 뷰가 없다면 외부 모드로 검사하고 해당 사실을 기록합니다.

NAVER 줌 단계는 이산적이므로 두 화면의 축척 숫자가 완전히 같을 필요는 없습니다. 반복 확대·축소나 진동 없이 비슷한 지상 거리/픽셀로 맞아야 합니다.
