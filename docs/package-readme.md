# Naver Map QGIS Bridge 0.2.0

QGIS에서 NAVER 지도·로드뷰를 확인하고 장소 검색, 자동차 경로, 경로 이력과 GIS 파일 내보내기를 사용하는 실험적 플러그인입니다. 지원 대상은 QGIS 3.34 LTR 이상과 QGIS 4.x입니다.

## 설치와 인증

QGIS의 **플러그인 관리 → ZIP으로 설치**에서 설치한 뒤 QGIS를 다시 시작합니다. 인증 설정 메뉴에서 NAVER Maps와 NAVER API HUB의 Client ID / Client Secret을 각각 입력합니다. 인증키는 공백 없는 인쇄 가능한 ASCII 문자여야 하며 QGIS 사용자 설정에 저장됩니다.

NAVER Maps에는 Dynamic Map, Geocoding, Directions 5가 필요합니다. 장소 검색에는 NAVER API HUB 지역 검색 인증 정보가 필요합니다. NAVER 콘솔의 Web URL에는 `http://localhost`를 등록합니다.

## 외부 브라우저

내장 웹 뷰를 사용할 수 없거나 외부 연동 창을 선택하면 localhost 포트 8083에 서버가 시작됩니다. 반드시 플러그인의 **외부 연동 창 열기** 버튼으로 새 탭을 여세요. 주소의 세션 토큰이 있어야 검색·경로·이력 명령을 사용할 수 있습니다. 이전 세션의 탭은 새 서버에 연결되지 않습니다.

같은 포트에 두 서버가 바인딩되지 않도록 보호합니다. 기본 포트를 사용할 수 없으면 운영체제가 할당한 별도 포트로 연동 창을 엽니다. 수동으로 주소를 입력하지 말고 플러그인의 열기 버튼을 사용하세요.

## 이력과 내보내기

이력 가져오기는 EPSG:4326 좌표계, 지오메트리, 좌표 범위, 안내 개수와 순서를 검사합니다. 과거 안내 분류는 NAVER 안내 코드에서 다시 계산합니다. 과거 파일 자체를 고치려면 가져온 뒤 다시 저장하세요.

SHP 필드의 UTF-8 바이트 폭을 초과하는 문자열·경유지 JSON은 잘라 저장하지 않습니다. 이 경우 GeoPackage 또는 GeoJSON을 사용하세요. GPX에서는 XML에서 허용되지 않는 제어문자를 제거합니다.

## 확인 범위

Python 회귀, 모의 NAVER SDK 웹 검사, QGIS 3.44.14 및 4.2.2의 오프라인 레이어·파일·HTTP·이력 검증을 수행했습니다. 2026-10-15 사용자는 수정본에 이상이 없다고 확인했습니다. 사용자 테스트의 QGIS 버전·브라우저 모드 및 개별 결과는 명시되지 않았습니다. 정확한 QGIS 3.34와 실제 NAVER SDK/API·내장/외부 화면의 환경별 전체 검증 기록은 별도로 확인해야 합니다.

[설치 후 수동 체크리스트](docs/install-test-checklist.md)를 참고하세요. 이 설치 ZIP은 개발용 테스트·빌드 도구를 포함하지 않습니다. 테스트와 개발 기록은 소스 작업 트리에서 관리합니다.
