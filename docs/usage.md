## 화면 열기와 배치

QGIS에서 **Naver Map / Street View**를 엽니다. 내장 웹 뷰가 없는 환경은 도크의 **외부 연동 창 열기**로 브라우저를 엽니다. 외부 모드도 QGIS가 실행 중이어야 합니다.

상단 배치 선택에서 지도 위 / 로드뷰 아래, 로드뷰 위 / 지도 아래, 지도 좌 / 로드뷰 우, 로드뷰 좌 / 지도 우를 선택합니다. 좁은 창에서는 좌우 배치도 상하로 조정될 수 있습니다. 가운데 분할선을 끌어 비율을 바꾸고 ⇅/⇄ 버튼으로 두 화면의 위치를 교환합니다. 전체화면 버튼으로 확장하고 Esc로 복귀합니다.

**탐색창 접기**는 검색과 경로 입력 영역만 접습니다. 처음 접을 때도 이력 탭은 표시되어 파일을 불러올 수 있습니다. 안내·이력 영역은 오른쪽 **− / +**로 따로 접고 펼칩니다. 빈 안내 탭을 선택해도 탭이 사라지지 않습니다. 이미 선택한 탭과 패널 접힘 상태는 탐색창을 접고 펼쳐도 유지합니다.

## 위치·축척·로드뷰

QGIS 캔버스와 NAVER 지도를 이동하면 중심이 서로 연동됩니다. 로드뷰에서 이동하면 지도와 QGIS 위치·방향 표시도 따라갑니다. 양쪽 확대·축소는 지상 거리 기준으로 가까운 단계에 맞추므로 축척 숫자가 정확히 같지는 않을 수 있습니다. 줌만 변경하면 로드뷰 촬영 위치는 유지합니다.

지도 유형은 일반지도 / 위성영상 / 위성영상+지명입니다. **로드뷰 도로 표시**로 촬영 도로 선을 확인할 수 있습니다. 지도 중심이나 경로를 변경하는 버튼은 아닙니다.

로드뷰의 촬영일은 API가 제공한 값을 표시합니다. 정보가 없으면 `촬영일 정보 없음`으로 표시하며, 촬영 날짜를 골라 과거 사진을 조회하는 기능은 아닙니다.

## 장소·주소·좌표 검색

검색창에 장소명, 도로명·지번 주소 또는 **경도,위도**를 입력하고 검색합니다. 좌표 예시는 `127.1,37.4`이며 위도를 먼저 쓰지 않습니다. 좌표는 장소 검색 API를 거치지 않고 위치 이동에 사용하지만 지도·로드뷰 표시에는 인터넷 연결이 필요합니다.

장소명은 NAVER API HUB 지역 검색을 사용하고 주소는 Maps Geocoding으로 처리합니다. 결과를 선택하면 해당 위치로 이동합니다. 검색 결과는 결과 선택이나 지도 클릭으로 숨겨지며 별도의 결과 펼치기 버튼은 없습니다. 기본 검색은 한글이며 EN 선택이 장소명·주소·사용자 입력을 번역하지는 않습니다.

## 자동차 경로 만들기

1. 출발과 도착에 장소·주소 또는 `경도,위도`를 입력합니다.
2. 필요한 경우 **+ 경유지**로 최대 5개를 추가합니다. 위/아래 버튼으로 순서를 바꾸거나 ×로 제거합니다.
3. 경로 유형과 회피·차량 설정을 확인합니다.
4. **경로 생성**을 누릅니다. 지도에 경로가 표시되고 QGIS에 경로선과 안내 포인트가 생성됩니다.
5. 안내 탭의 항목을 누르면 해당 위치로 이동하고 대응하는 QGIS 안내 피처가 선택됩니다.

출발·도착·경유지의 **현재 위치**는 NAVER 지도 중심입니다. GPS를 조회하지 않습니다. ⇅는 출발·도착을 교환하고, 경로 입력의 ×는 입력을 초기화합니다.

### 경로 옵션

| 설정 | 동작 |
| --- | --- |
| 실시간 최적 / 실시간 빠른길 / 실시간 편한길 | NAVER Directions 5 경로 유형. 편한길은 최단거리와 다름 |
| 무료 우선 / 자동차전용도로 회피 | 하나만 선택하며 위 경로 유형을 대체. 해제하면 유형 선택 복원 |
| 차종·유종 | API의 통행료·유류비 계산 설정 |
| 하이패스 | 경로 선택 설정은 API 미지원으로 비활성화. 하이패스 톨게이트 안내는 나올 수 있음 |
| 이륜차 | 자동차용 API이므로 지원하지 않음 |

**취소**는 진행 중인 경로 탐색을 중단합니다. 경로 API 요청 제한은 30초이고 브리지 응답이 누락되면 웹 입력창은 35초 복구 절차를 사용합니다. 출발·도착의 장소 해석 시간은 별도입니다.

## EN / KR와 영문 지명

최초 기본 언어는 한글입니다. **EN**은 영어로, **KR**은 한국어로 전환하는 버튼이며 같은 브라우저 프로필에서 선택을 기억합니다. 위치·줌·경로 입력·표시 경로를 보관한 뒤 뷰어를 다시 로드합니다. 검색·경로 처리 중에는 전환을 마친 뒤 사용합니다.

| 대상 | 언어 전환 동작 |
| --- | --- |
| 지도 SDK·웹 조작부 | 선택 언어로 전환 |
| 새로 생성하는 경로 | EN은 `lang=en`, KR은 `lang=ko`로 API에 요청 |
| 기존 한글 안내 | EN에서 알려진 안내 형식만 영어로 표시. 지명은 저장 원문 유지 |
| 영어로 생성·저장한 안내 | KR 전환만으로 새 한글 원문이 생성되지는 않음 |
| 장소 검색 결과·사용자 입력·QGIS 메뉴와 대화상자 | 자동 번역하지 않음 |

`광화문`, `세종대로` 같은 지명까지 영문 안내로 받으려면 **EN 선택 → 새 경로 생성** 순서로 사용하세요. 표기는 API가 제공하는 값을 사용합니다. 기존 이력은 자동 재조회하지 않으므로 언어 전환으로 경로가 달라지거나 추가 API 호출이 발생하지 않습니다. 안내에 마우스를 올리면 저장된 원문을 확인할 수 있습니다. 미지원 안내 형식은 원문을 그대로 표시합니다.

## 이력 불러오기와 삭제

경로 생성 후 이력 탭에서 이전 결과를 선택하면 경로와 안내를 다시 볼 수 있습니다. **불러오기**는 저장된 출발·경유·도착 및 옵션을 입력창으로 불러옵니다. 변경한 언어·입력으로 다시 조회하려면 **경로 생성**을 누릅니다.

이력 탭의 **파일 불러오기** 또는 QGIS의 **경로 이력 불러오기...**로 GeoPackage·GeoJSON·Shapefile 이력을 가져옵니다. 파일 선택 창에서 Ctrl/Shift로 여러 파일을 선택할 수 있습니다. 동일 이력은 중복 추가하지 않으며, 파일 검증이나 가져오기가 실패하면 해당 일괄 작업을 복구합니다.

각 이력의 체크박스 또는 **전체 선택 → 선택 삭제**로 여러 이력을 삭제합니다. 확인 후 현재 세션의 이력과 안내가 삭제되며 원본 파일은 삭제하지 않습니다. 현재 표시 중인 이력을 삭제하면 경로 표시도 초기화됩니다.

## 저장과 내보내기

이력은 자동으로 파일에 저장되지 않습니다. 종료·업데이트 전에 QGIS 플러그인 메뉴의 **경로 이력 GeoPackage 저장...**을 사용하세요. 개별 이력의 **내보내기**도 사용할 수 있습니다.

| 형식 | 사용 목적과 주의점 |
| --- | --- |
| GeoPackage | 경로·안내·입력 속성을 함께 보존하고 재불러오기. 기본 권장 형식 |
| GeoJSON | 다른 GIS 도구와 교환. 생성된 경로·안내 파일을 함께 보관 |
| Shapefile | 기존 GIS 작업과 교환. 구성 파일과 경로·안내 쌍을 모두 보관 |
| GPX | 트랙·웨이포인트 교환. 플러그인의 스타일 적용 불러오기 메뉴 제공 |

SHP는 UTF-8 문자열·경유지 JSON이 필드 한도를 넘으면 잘라 저장하지 않고 오류를 표시합니다. 이 경우 GPKG 또는 GeoJSON을 사용합니다. GPX는 일반 교환용이며 플러그인의 완전한 이력 복원은 GPKG를 우선 사용하세요.

가져오기는 좌표계(EPSG:4326), 형상·좌표 범위, 경로·안내 대응을 검사합니다. 기존 파일의 안내 분류는 가져오거나 내보낼 때 보정합니다. 원본 파일에 반영하려면 별도로 다시 저장합니다. 카카오 플러그인의 GPKG 경로 비교로 연결하려면 [요금 비교 안내](fare-comparison.md)를 참고하세요.

## 프로젝트 전환과 종료

새 프로젝트를 만들거나 다른 프로젝트를 열면 진행 요청과 현재 경로·입력은 초기화됩니다. 같은 실행 세션의 이력은 남아 선택할 수 있습니다. QGIS 종료 또는 플러그인 재시작 후까지 세션 이력 보존을 보장하지 않으므로 필요한 결과를 파일로 저장합니다.

사용 중 이상이 있으면 [문제 해결](troubleshooting.md)에서 증상을 확인하고 [설치 체크리스트](install-test-checklist.md)로 재현 조건을 기록하세요.
