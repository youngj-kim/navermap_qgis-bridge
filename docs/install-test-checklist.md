# 설치 테스트 체크리스트 — 2026-10-27

한국어 | [English](install-test-checklist.en.md)

대상: `0.2.0` 개발본. [설치와 설정](setup.md) · [사용 가이드](usage.md). 체크는 실제 화면에서 기대 결과를 확인했을 때만 표시합니다. 자동/오프라인 검증은 완료했지만 실제 NAVER 연동과 정확한 QGIS 3.34 검증은 남아 있습니다.

## 1. 준비와 설치

- [ ] QGIS 버전·운영체제·테스트 ZIP 파일명을 기록했습니다.
- [ ] 개발 소스를 연결한 프로필과 구분되는 테스트용 QGIS 프로필을 준비했습니다.
- [ ] **플러그인 관리 → ZIP으로 설치**에서 ZIP을 설치하고 QGIS를 다시 시작했습니다.
- [ ] 플러그인 메뉴/툴바가 한 번씩 표시되고 뷰어가 열립니다.
- [ ] NAVER Maps와 API HUB 인증 정보를 로컬 설정에 입력했습니다. 지도·로드뷰가 표시되고 인증 오류가 없습니다.

인증키는 체크리스트·스크린샷·오류 보고에 적지 않습니다. QGIS 3과 4의 외부 브라우저 검사는 순서대로 수행합니다. 기본 포트 8083을 사용하는 이전 QGIS 외부 연동은 종료하고, 기존 브라우저 탭 대신 플러그인에서 새 탭을 엽니다.

## 2. 우선 확인: 위치와 확대·축소

아래 묶음은 **QGIS 3.34 이상 외부 브라우저**, **QGIS 4 내장 웹 뷰**에서 각각 확인합니다. QGIS 4에 내장 웹 뷰가 없다면 외부 모드로 검사하고 해당 사실을 기록합니다.

- [ ] QGIS 캔버스를 이동하면 NAVER 지도와 로드뷰가 해당 위치로 이동합니다.
- [ ] NAVER 지도를 드래그하면 QGIS 중심이 이동합니다. 손을 놓은 후 화면이 반복해서 튀지 않습니다.
- [ ] 로드뷰 내부에서 이동하면 지도/QGIS 위치 및 방향 표시가 따라옵니다.
- [ ] QGIS에서 휠로 확대·축소하면 NAVER 지도도 가까운 축척으로 바뀝니다. **로드뷰 촬영 위치와 위치 마커는 유지**됩니다.
- [ ] NAVER에서 휠과 확대·축소 버튼을 사용하면 QGIS 축척이 따라옵니다. **로드뷰 촬영 위치와 위치 마커는 유지**됩니다.
- [ ] 마우스 위치를 중심으로 확대·축소해도 로드뷰가 불필요하게 다른 장소로 이동하지 않습니다.
- [ ] 프로젝트 CRS를 EPSG:4326, EPSG:3857 및 평소 사용하는 투영 좌표계로 바꾸어 위 이동/확대·축소를 확인했습니다.

NAVER 줌 단계는 이산적이므로 두 화면의 축척 숫자가 완전히 같을 필요는 없습니다. 반복 확대·축소나 진동 없이 비슷한 지상 거리/픽셀로 맞아야 합니다.

## 3. 화면과 지도 설정

- [ ] 탐색창을 접어도 옆의 뷰 배치 선택으로 네 가지 배치를 바꿀 수 있습니다. 다시 펼치면 검색어·출발/도착·경유지·결과가 남아 있습니다.
- [ ] 검색하면 결과 목록이 바로 표시되고, 결과 선택/지도 클릭 시 숨겨집니다. 별도의 검색 결과 펼치기 버튼은 없습니다.
- [ ] 일반지도 → 위성영상 → 위성영상+지명 전환이 됩니다. 위치·경로·로드뷰 촬영 위치가 유지됩니다.
- [ ] **로드뷰 도로 표시/숨기기**로 촬영 도로 선이 켜지고 꺼집니다. 로드뷰 촬영일이나 촬영 위치를 바꾸는 기능이 아닙니다.
- [ ] 지도 위/로드뷰 위/지도 좌/로드뷰 좌 네 배치에서 분할선을 움직이고 위치를 전환할 수 있습니다.
- [ ] 도크를 분리·재도킹하고 창을 크게/작게 바꾸어도 흰 여백·잘림·버튼 가림이 없습니다. 첫 분리창이 화면 밖으로 크게 벗어나지 않습니다.
- [ ] 전체화면 전환과 Esc 복귀가 됩니다.
- [ ] 로드뷰 이동 시 촬영일이 갱신됩니다. 정보가 없는 곳은 이전 날짜 대신 **촬영일 정보 없음**이 표시됩니다.

## 4. 검색과 경로 설정

- [ ] `127.1,37.4` 좌표 입력으로 이동합니다. 장소 검색 결과 목록을 기다리지 않습니다.
- [ ] `서울역` 같은 장소명, 도로명 주소, 지번 주소 검색과 결과 선택 이동이 됩니다.
- [ ] 장소 검색 직후 좌표를 입력해 이동했을 때, 늦게 도착한 이전 장소 결과가 좌표 선택을 덮어쓰지 않습니다.
- [ ] 출발/도착과 경유지 1개 이상으로 경로를 만들고 경로선·안내 포인트가 표시됩니다.
- [ ] 출발/도착 교환, 경유지 위/아래 이동 및 삭제가 다음 조회에 반영됩니다. 경유지는 최대 5개입니다.
- [ ] 무료 우선과 자동차전용도로 회피를 동시에 선택할 수 없습니다. 회피 선택 시 경로 유형 선택이 비활성화되고, 완료 메시지는 실제 선택한 회피 옵션을 표시합니다.
- [ ] 회피를 해제하면 실시간 최적/빠른길/편한길을 다시 선택할 수 있습니다. 편한길이 최단거리로 표시되지 않습니다.
- [ ] 하이패스는 **미지원**으로 비활성화되고 이륜차는 차량 목록에 없습니다.
- [ ] 안내 항목을 선택하면 해당 지점으로 이동하고 QGIS의 대응 안내 피처가 선택됩니다.

## 5. 취소·오류·프로젝트 전환

- [ ] 장소명으로 출발/도착을 입력하고 경로 생성 직후 취소합니다. 늦은 위치 검색 때문에 경로가 다시 생성되지 않으며 입력창을 다시 사용할 수 있습니다.
- [ ] 경로 응답 대기 중 취소하면 대기가 해제되고 다시 조회할 수 있습니다. 이미 완료된 경로는 취소 대상으로 간주하지 않습니다.
- [ ] 네트워크를 일시적으로 끊은 상태에서 조회하면 오류 또는 시간 초과가 표시되고 입력창이 복구됩니다. API 응답 대기 제한은 30초, 브리지 응답 누락 시 웹 복구는 35초입니다. 장소 좌표 해석 시간은 별도입니다.
- [ ] 경로 조회 중 새 프로젝트를 만들거나 다른 프로젝트를 엽니다. 이전 요청이 새 프로젝트에 경로를 뒤늦게 생성하지 않습니다.
- [ ] 프로젝트 전환 후 현재 경로·안내·입력 핀/입력창은 초기화되고 **세션 이력은 유지**됩니다. 이력을 선택하면 새 프로젝트에 다시 표시됩니다.
- [ ] 저장/불러오기 대화상자 도중 프로젝트가 전환된 경우, 이전 작업이 새 프로젝트에 적용되지 않습니다. 해당 상황을 재현하지 못하면 미수행으로 적습니다.
- [ ] 플러그인을 비활성화했다 다시 활성화해도 메뉴/도크가 중복되지 않습니다. 플러그인 종료·재시작 후 세션 이력 유지까지 요구하는 항목은 아닙니다.

응답이 너무 빨라 취소·시간 초과를 재현하지 못한 항목은 통과 대신 **미수행**으로 기록합니다. 반복적인 실제 API 조회는 필요하지 않습니다.

## 6. 이력과 파일

- [ ] 새 경로의 이력을 선택·입력 불러오기·삭제할 수 있습니다.
- [ ] GeoPackage로 저장하고 다시 불러오면 경로·안내·입력 정보가 유지됩니다.
- [ ] GeoJSON·Shapefile·GPX를 각각 내보내고 QGIS에서 다시 열어 좌표·형상·주요 속성을 확인했습니다.
- [ ] 새 조회의 통행료/예상 택시요금이 GPKG·GeoJSON·SHP 속성에 보존됩니다. 요금 없는 기존 파일은 NULL이며 0원으로 바뀌지 않습니다.
- [ ] 예전 대문자 연료 값/복수 회피 설정의 이력을 불러와도 예외가 없습니다. 복수 회피는 당시 실제 적용된 무료 우선으로 불러왔다는 안내가 표시됩니다.
- [ ] 카카오 플러그인도 설치되어 있다면 카카오의 **GPKG 경로 비교**에서 새 NAVER GPKG를 열어 거리·시간·통행료·택시요금을 확인했습니다. 카카오 플러그인이 없으면 미수행으로 기록합니다.

GPX의 기존 확장 형식은 유지하며, 이번 요금 비교의 입력 형식은 GPKG입니다.

## 7. 안내·이력과 언어 전환

- [ ] 최초 실행에서 탐색창을 접어도 이력 탭과 파일 불러오기가 표시됩니다.
- [ ] 빈 이력에서 안내 탭을 눌러도 탭이 남고 빈 안내 문구가 표시됩니다. −/+로 접고 다시 펼칠 수 있습니다.
- [ ] 탐색창 접기·펼치기가 이미 선택한 안내/이력 탭과 패널 접힘 상태를 바꾸지 않습니다.
- [ ] 이력 파일을 여러 개 불러오고, 중복 파일을 다시 선택해도 이력이 중복되지 않습니다.
- [ ] 체크박스·전체 선택·선택 삭제가 동작합니다. 삭제 취소 시 이력과 원본 파일이 유지됩니다.
- [ ] 최초 기본 언어와 장소 검색이 한글입니다. EN/KR 전환 후 지도·입력·표시 경로가 유지됩니다.
- [ ] EN에서 새 경로를 생성하면 API가 제공하는 영문 지명 안내가 표시되고 KR에서 새로 생성하면 한글 안내가 표시됩니다.
- [ ] 기존 이력은 언어 전환만으로 재조회되지 않고 저장 원문을 유지합니다. 한글 안내의 알려진 형식은 EN에서 변환되며 원문 툴팁을 확인할 수 있습니다.
